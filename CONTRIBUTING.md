# Contribution Guide 🤝

Merci d'être intéressé par la contribution au projet Chaîne TV + VidSrc!

## Comment contribuer?

### 1. Fork et Clone

```bash
git clone https://github.com/votre-username/chaine-tv-vidsrc.git
cd chaine-tv-vidsrc
```

### 2. Créer une branche

```bash
git checkout -b feature/ma-nouvelle-fonctionnalite
```

### 3. Apporter les modifications

- Respectez le style de code existant
- Utilisez TypeScript pour la sécurité des types
- Testez vos modifications

### 4. Commit

```bash
git commit -am 'Ajouter ma nouvelle fonctionnalité'
```

### 5. Push et Pull Request

```bash
git push origin feature/ma-nouvelle-fonctionnalite
```

Ensuite, ouvrez une Pull Request sur GitHub.

## Standards de Code

- Utilisez des noms de variables descriptifs
- Ajoutez des commentaires pour la logique complexe
- Formatez avec Prettier
- Testez vos changements

## Signaler des Bugs

Utilisez l'onglet Issues pour signaler des bugs avec:
- Description détaillée
- Étapes pour reproduire
- Résultat attendu vs résultat actuel

Merci pour votre contribution! 🎉
